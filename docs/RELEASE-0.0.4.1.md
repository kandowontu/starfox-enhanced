# 0.0.4.1 ALPHA

- Added ACCURATE pace as the fresh/reset default, using native CPU/GSU timing while retaining enhanced rendering and interpolation. Existing saved ORIGINAL and UNLOCKED choices remain available.
- Corrected EX boss model scaling, Sector Y map artwork, route endpoint handling, and credits Start handoffs.
- Improved native audio timing, MSU credits handoffs, short gameplay button taps, pause presentation, and controller rumble servicing.
- Added MSU-off boss-death audio checks for both ports and both schedulers. The reported continuation was not reproduced in current code.

The complete automated suite passed **95/95** on the released runtime changes. This is an alpha, not certification of full 1:1 parity. ACCURATE still needs full campaign and hardware validation; God Mode enhancements and some pause-menu/control cases remain unfinished. ORIGINAL remains available for users who prefer the previous pace implementation. The delayed credits-jingle and one-ship Star Wolf reports were not reproduced in the covered tests.

Platform builds are being generated by GitHub Actions and will appear as they finish. Game ROMs and generated game asset BIN files are not included. Existing compatible asset BIN and optional MSU PAK files can be reused.

Full changelog: https://github.com/kandowontu/starfox-enhanced/compare/v0.0.4...v0.0.4.1
