OPTIONAL NVIDIA DLSS RUNTIME

This folder is part of Star Fox Enhanced's Windows x64 distribution.
Keep it beside starfox_pc.exe. No separate download or installer is required.
Select DLSS in 3D OPTIONS when using a compatible NVIDIA GPU and D3D12.
DLSS defaults to OFF; unsupported systems retain normal rendering.

This package does not include RenoDX, ReShade, or the DLSS5 neural-rendering
add-on. DLSS5 (EXP.) appears only with a separately installed, compatible
experimental add-on and explicit startup configuration. Its ON/OFF preference
requires restarting the game; this package alone does not provide that effect.
