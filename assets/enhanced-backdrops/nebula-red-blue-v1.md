# Red/blue nebula panorama

Generated September 20, 2026 using the built-in image-generation tool and
the imagegen skill. Original PNG preserved at 2172x724; BMP is a lossless
RGB format conversion for resource 207. Used by EX menu choice 2 only when
Enhanced Sky is enabled. No cartridge artwork or game UI is in this asset.

Final prompt:

Use case: photorealistic-natural. Asset type: seamless horizontally tileable game nebula backdrop texture, wide 3:1 panorama. Primary request: a realistic deep-space astronomical nebula of crimson emission gas and cobalt-blue reflection clouds, with dark dust filaments and many fine, sharp distant stars. This replaces a red/blue nebula background in a space flight game. Composition: intricate organic diffuse cloud shapes spread throughout the full image, no central glowing sun, no planet, no horizon, no ground, no ship, no text. Photographic telescope detail, restrained natural contrast with dark negative space so white game menu lettering stays readable. Seamless left/right edges with consistent brightness across the image, no vignette, no lens flare, no border, no watermark. One continuous panorama, not a contact sheet.

The runtime panorama sampler blends a narrow horizontal overlap; the generated
edge pixels are not assumed to be mathematically periodic.
