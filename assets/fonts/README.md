The original BDF and author documentation are retained for reproducible glyph
generation. Localized rendering must validate coverage rather than substitute
blank glyphs for unsupported characters. English and localized menu Latin
letters use the cartridge font; menu accents are drawn separately. Misaki
supplies Japanese menu glyphs and compact translated in-game dialogue.
